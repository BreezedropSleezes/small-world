独立开发 · 体素世界模拟

我在做一个
会自己运转的世界。

没有玩家操作时，居民也会饿、会累，会自己找食物、找地方休息，也会避开危险。世界按自己的规则继续变化。

我想做的不是一张等待玩家推动的地图，而是一个没有主角也能成立的地方。

项目

一个没有玩家也会继续的世界

这是一个体素模拟项目。地形、材料、时间、昼夜、温度和燃烧共享同一套规则。树被砍倒，食物被吃掉，材料被搬走，世界会留下痕迹。

居民有饥饿和疲劳。他们会观察周围，决定去哪里、做什么，再通过砍伐、采集、搬运改变世界。玩家以后可以引导村庄，但不会代替居民生活。

我先要解决的是一个观察问题：看着一个居民走过去，能不能说出他为什么这么走。建造和玩家指令都放在这之后。

需求衰减→ 感知→ 决策→ 行动→ 世界变化

怎么读

从上往下是剖面。最上层是画面，中间是居民与实体，底层是世界模拟和确定性底座。

材料决定变化。温度、燃烧、液体读写同一份体素，彼此不点名。

居民改世界，画面只看。决策不直接改格子；砍、采、搬才留下痕迹。

同一种子，同一种结果。关掉玩家，世界仍按这张剖面转。

关于

关于我

我是 BreezedropSleezes，独立开发者。我喜欢看系统自己跑起来，再从画面里反推它为什么这么跑。

这个项目从世界规则开始：先让世界成立，再考虑玩家怎么参与。我在意的是，一个没有玩家推动的世界，能不能仍然让人看懂。

目前在做第二阶段：把居民从“看见”接到“建造”，让一次完整的生活流程能被观察。

我负责方向、规则和验收；实现上用 Unity 和 C#，并借助 AI 做代码起草、资料检索和重复检查。工具不替我做决定。

如果你也在做模拟、智能体或体素方向的东西，欢迎在 GitHub 找我。

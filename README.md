# BreezedropSleezes · 体素世界模拟

做成的页面在这里：**[打开页面](https://breezedropsleezes.github.io/small-world/)**

这是一个个人主页，也是项目的公开记录。项目是一个没有玩家操作也会继续运转的体素世界；游戏工程不在这个仓库里。

## 页面里有什么

- 项目：世界规则、居民循环、确定性。
- 现在：四行进度表，讲清世界、居民、行为和底座做到哪。
- 居民：一段摘要 + `resident.html`；结构页放目标 → 处境 → 评估 → 执行 → 反思 → 反馈。
- 日志：第一篇记录第一阶段收尾与居民行为接入。
- 关于：开发方式与 GitHub。

## 现在

- 世界模拟已经可以独立运行；鹿已进入世界；居民能够感知、决策并行动。
- 建造、寻路和材料搬运仍在完善，第二阶段尚未完成。
- Windows 包还没放上来。有了会挂在 [Releases](https://github.com/BreezedropSleezes/small-world/releases)。

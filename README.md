# BreezedropSleezes · 会自己运转的体素世界

做成的页面在这里：**[打开页面](https://breezedropsleezes.github.io/small-world/)**

这是一个个人主页，也是项目的公开记录。项目是一个没有玩家操作也会继续运转的体素世界；游戏工程不在这个仓库里。

## 页面里有什么

- 项目：世界规则、居民循环、确定性。
- 画面：三张当前开发版本的游戏内截图。
- 进度：世界自转、居民自己活、玩家引导村庄三个阶段。
- 技术：整体 / 世界 / 居民 / 时钟四视图系统地图。
- 日志：第一篇记录第一阶段收尾与居民行为接线。
- 关于：开发方式与 GitHub。

## 现在

- 世界已经能独立运转；鹿已进入世界；居民能感知、决定并行动。
- 建造、寻路和材料搬运还在补，第二阶段尚未收官。
- Windows 包还没放上来。有了会挂在 [Releases](https://github.com/BreezedropSleezes/small-world/releases)。

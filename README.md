# 这个世界

做成的页面在这里：**[打开页面](https://breezedropsleezes.github.io/small-world/)**

这是一个公开页，用来看这个项目在做什么、做到哪。游戏工程不在这个仓库里。

## 这是什么

我在 Unity 里做一套会自己运转的小世界。居民会饿、会累，自己去找吃的、找地方休息，也会躲开狼。天黑、燃烧、把东西砍掉或搬走，都会改变这个世界。

我想先做明白一件事：看着一个居民走过去，能说出他为什么这么走。

## 现在

- 世界已经会转。白天黑夜、冷热都在走。
- 鹿已经放进世界。人能看见旁边有什么，再决定要做什么。
- 盖房、找路、把材料搬去工地，还在做。
- Windows 安装包还没放上来。有了会挂在 [Releases](https://github.com/BreezedropSleezes/small-world/releases)。
